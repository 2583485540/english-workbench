☁️ 跨电脑数据同步（百度网盘）

数据保存在当前浏览器里，换电脑时按下面 4 步同步：

  1. 点 「导出数据」，浏览器下载 english-workbench-data.json
  2. 登录百度网盘，上传到 我的应用数据/bdpan/english-workbench/（覆盖同名文件）
  3. 另一台电脑打开本网站，从网盘把最新 JSON 下载到本地
  4. 点 「导入数据」 选择该 JSON → 选择「合并」→ 完成 ✅
